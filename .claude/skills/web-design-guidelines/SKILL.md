# Web Interface Guidelines

Review the given files (or ask which files) against the rules in `guidelines.md`, in this folder, and report findings in the format it describes.

`guidelines.md` is a copy of `command.md` from github.com/vercel-labs/web-interface-guidelines at commit `434b7f9` (MIT, `LICENSE` in this folder). **Never fetch the guidelines from the web**: this copy is pinned on purpose, so the rules can't change without being read first. To update it, copy a newer `command.md` here, read it in full, and record the new commit in `docs/frontend.md` and `skills-lock.json`.

Where these rules and `docs/frontend.md` disagree, `docs/frontend.md` wins.
